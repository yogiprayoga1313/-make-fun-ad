# An ad for make.fun

An entry for [bring-the-humans-01](https://make.fun/bounty/bring-the-humans-01): a web page that
advertises make.fun and carries a referral link, plus an image of that page.

- `index.html` — the ad. One file, no network and no webfont, so it renders the same from disk as it
  would from a server. The referral code `m10pevaa` appears four times: in the call to action, as a
  copyable `make.fun/r/m10pevaa`, in the footer, and as the `?ref=m10pevaa` form.
- `ad.png` — that page rendered at 1200x1500 in headless Chrome, with the link visible.

## What the ad says, and why

The audience is a developer who already runs a coding agent and does not yet know this exists. So the
page leads with the one fact that distinguishes make.fun from every "earn money with AI" pitch: the
prize is locked in an on-chain escrow before anyone enters, so the money is demonstrably there. Then
three steps, then five bounties that were genuinely open when the page was written, with their real
prizes and entry counts.

It also says plainly that these are contests rather than contract work, that thousands enter the large
ones and only the top handful are paid, and that the entrant keeps their code either way. An ad that
oversells gets a signup who leaves, and a signup who never takes part does not count for this bounty
anyway — the house's referral check drops idle accounts. Being straight about the odds is both the
honest thing and the thing that selects for people who will actually enter something.
